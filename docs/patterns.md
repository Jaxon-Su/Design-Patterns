# C++ 設計模式中文說明

## 建立型 Creational

### Abstract Factory
一句話：建立一整組相容物件，而呼叫端不用知道具體類別。

適合用在：同一套系統需要切換不同產品族，例如深色/淺色 UI 元件、不同儀器品牌的 Driver 物件。

原創例子：`ThemeFactory` 同時產生 Button 與 Checkbox，確保都是同一種主題。

### Builder
一句話：把複雜物件的建造步驟拆開，最後再組成完整結果。

適合用在：建構參數很多、步驟有順序、不同組合會得到不同物件。

原創例子：`ReportBuilder` 逐步加入標題、圖表、表格，最後輸出報告。

### Factory Method
一句話：父類別定義建立物件的流程，子類別決定實際建立哪一種產品。

適合用在：框架知道「何時需要產品」，但不知道「該用哪個具體產品」。

原創例子：不同 `LogisticsApp` 建立卡車或無人機配送任務。

### Prototype
一句話：用複製既有物件來建立新物件，避免重新設定複雜初始狀態。

適合用在：物件建立成本高，或有一批只差少數欄位的配置。

原創例子：複製一份預設感測器設定，再改成不同站點名稱。

### Singleton
一句話：確保全系統只有一個共用實例，並提供全域存取點。

適合用在：全域唯一資源，例如設定中心、硬體連線管理器。請避免濫用，否則會讓測試與依賴關係變硬。

原創例子：`AppConfig` 儲存程式啟動後的環境名稱。

## 結構型 Structural

### Adapter
一句話：把既有類別的介面轉成呼叫端期待的介面。

適合用在：新系統要接舊 API、第三方 SDK、硬體函式庫。

原創例子：舊溫度 API 回傳華氏，Adapter 提供攝氏介面。

### Bridge
一句話：把抽象層與實作層分離，兩邊可以各自擴充。

適合用在：功能維度與平台維度會各自成長，例如通知內容與傳送通道。

原創例子：`RemoteControl` 操作不同種類的 `Device`。

### Composite
一句話：把單一物件與物件群組用同一種介面處理。

適合用在：樹狀結構，例如 UI 元件、檔案系統、組織架構。

原創例子：資料夾包含檔案與子資料夾，計算總大小時使用同一介面。

### Decorator
一句話：在不修改原類別的情況下，動態加上額外行為。

適合用在：功能可以層層疊加，例如壓縮、加密、快取、記錄。

原創例子：飲料先有基底，再加牛奶與珍珠。

### Facade
一句話：提供簡單入口，封裝背後複雜子系統。

適合用在：外部只需要常用流程，不需要碰所有細節。

原創例子：`VideoExportFacade` 封裝載入、編碼、寫檔。

### Flyweight
一句話：共享大量物件中重複不變的內部狀態，節省記憶體。

適合用在：大量小物件，例如文字字元、地圖標記、棋盤格。

原創例子：地圖上多個樹木共享同一份樹種資料，只保存座標差異。

### Proxy
一句話：用代理物件控制對真實物件的存取。

適合用在：延遲載入、權限檢查、遠端呼叫、快取。

原創例子：`ImageProxy` 第一次顯示時才載入大型圖片。

## 行為型 Behavioral

### Chain of Responsibility
一句話：讓請求沿著處理鏈傳遞，直到某個物件能處理。

適合用在：審核流程、事件處理、例外分類。

原創例子：客服單依嚴重程度交給一線、工程師或主管。

### Command
一句話：把一個操作包成物件，方便排程、撤銷、重做與記錄。

適合用在：UI 按鈕、巨集、工作佇列、undo/redo。

原創例子：文字編輯器把「加入文字」包成 Command。

### Iterator
一句話：不用暴露容器內部結構，就能逐一走訪元素。

適合用在：自訂集合需要提供穩定走訪方式。

原創例子：播放清單提供下一首歌曲。

### Mediator
一句話：把多個物件之間的複雜互動集中到中介者。

適合用在：UI 控制項互相影響、聊天室、模組協調。

原創例子：登入表單由 `LoginDialog` 協調帳號欄、密碼欄與登入按鈕。

### Memento
一句話：保存物件狀態快照，之後可以還原。

適合用在：undo、版本回復、暫存編輯狀態。

原創例子：草稿文件儲存歷史版本。

### Observer
一句話：主體狀態改變時，自動通知所有訂閱者。

適合用在：事件系統、資料綁定、訊號通知。

原創例子：股票價格更新後通知手機 App 與儀表板。

### State
一句話：物件在不同狀態下有不同反應，狀態本身封裝行為。

適合用在：流程狀態機，例如訂單、連線、播放器。

原創例子：播放器在停止與播放狀態下，按下 play 的行為不同。

### Strategy
一句話：把可替換演算法封裝起來，執行時選擇策略。

適合用在：排序、折扣、路徑規劃、資料匯出格式。

原創例子：購物車結帳時套用會員折扣或節慶折扣。

### Template Method
一句話：父類別固定演算法骨架，子類別填入特定步驟。

適合用在：流程固定但細節不同，例如資料匯入、測試流程、報表生成。

原創例子：不同飲品共用「煮水、沖泡、倒杯」流程，但沖泡內容不同。

### Visitor
一句話：把作用在物件結構上的新操作獨立出來，避免修改元素類別。

適合用在：物件結構穩定，但常增加新操作。

原創例子：圖形物件可被面積計算 Visitor 與匯出 Visitor 拜訪。
